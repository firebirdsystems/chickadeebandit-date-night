# Date Night Planner

A [Chickadee Bandit](https://chickadeebandit.com/app-library/date-night-planner) app.

Build a shared catalog of date ideas and let the app pick one when you need inspiration.

## Features

- A shared catalog of date ideas, tagged by vibe.
- Surprise Me picks one at random.
- Mark dates done with a star rating.
- Browse your history together.
- Private to the two of you. Adults only.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-date-night/releases/latest/download/bundle.json
```
